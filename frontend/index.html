Getting started in 3 steps

Simple setup designed to protect local and production environments in seconds.

1

Download Extension

Click Download to grab the shim-vscode-extension.vsix package directly to your computer.

1-Click VSIX Package
2

Select File in VS Code

In VS Code, press Ctrl+Shift+X, click the three dots ... at the top of the Extensions sidebar, click Install from VSIX..., and choose the downloaded file.

Extensions → ... → Install from VSIX
3

Guard Your APIs

Route your requests through the SHIM Proxy (port 8000). The extension displays 🛡️ SHIM: Active in your status bar and alerts you when schemas drift.
